## Диагностические заметки

Материалы описывают конкретные расследования и не требуют воспроизведения
сбоев для обычного запуска проекта.

- [WebDriver Monitor](webdriver-diagnostics.md) — сохранённый opt-in механизм;
  в текущем Pipeline выключен.
- [Web UI и Mobile после №23](ci-stability.md) — историческая блокировка сайта
  и диагностика instrumentation.
- [Mobile preflight №14–15](mobile-preflight-diagnostics.md) — прошлые ошибки
  подготовки; актуальный runner описан отдельно.

Экспериментальная Android readiness не входит в опубликованный baseline №29.
Её локальные материалы не являются инструкцией по настройке текущего CI.
