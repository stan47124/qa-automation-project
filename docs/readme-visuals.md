## История и область данных

Последний столбец Status dynamics соответствует успешному №29. Предыдущие
failed/broken сохранены. Сам снимок показывает даты; номера №23–29 установлены
по исходному снимку истории. Нельзя представлять эту историю как семь успешных
запусков или подменять её графиком из отчёта без истории.

В текущих результатах №29 только 22 активных теста трёх приложений.
Исторический SauceDemo может присутствовать в Coverage diff map исходного
отчёта как удалённые тесты предыдущего запуска; в галерею этот график не включён.
[Причина и отдельное представление без истории](allure-final-report.md).
Ни результаты, ни постоянная история ради оформления не менялись.
