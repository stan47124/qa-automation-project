## Изменения

- `tests/mobile/mobile_config.py`: единые package, activity, Appium URL, устройство, таймаут и базовая директория.
- `tests/mobile/material_files.py`: существующий FilesScreen вынесен из тестов; общая обработка стартового диалога и создания папки. Поиск по resource ID и тексту использует UiSelector; XPath меню ограничен ближайшей строкой itemLayout. Использованы ранее подтверждённые идентификаторы.
- `tests/mobile/conftest.py`: fixtures используют общие настройки; files_screen перенесена сюда из функционального модуля. Адресная очистка уникальных директорий сохранена.
- `tests/mobile/test_material_files_smoke.py`: общая обработка запуска; сохранены проверки главного экрана и package.
- `tests/mobile/test_material_files_functional.py`: сохранены пять сценариев; тест открытия проверяет только собственный sample.txt. Создание папки использует общий UI-метод.
- Сохранён повтор поиска и клика при StaleElementReferenceException через WebDriverWait. time.sleep() не используется.
- API- и Web UI-тесты не изменялись.

Исходный `/sdcard/Download/qa_guru/sample.txt` не используется как тестовые данные и не изменяется. Контрольная сумма SHA-256 до прогонов:

```text
6fafa10b75b2686f6868e42d339fa988a724030fd71bc1f282f303975bbb00e3
```

После трёх прогонов SHA-256 совпадает с исходной. Команда `adb -s emulator-5554 shell ls -la /sdcard/Download/qa_guru` показывает только исходный sample.txt (24 байта); временных test_<uuid> не осталось. Пользовательские файлы не удалялись.

## Оставшиеся риски

- Текстовые пункты меню, описание диалога и accessibility labels зависят от английского языка приложения.
- Меню файла находится по подтверждённым nameText/itemLayout/menuButton; изменение структуры строки в новой версии приложения потребует обновления XPath.
- Нужны работающие Appium, UiAutomator2, emulator-5554 и существующая базовая директория /sdcard/Download/qa_guru. Проверка запуска приложения не создаёт файлов, остальные тесты готовят собственные данные.
- noReset сохраняет настройки приложения; сторонние действия на устройстве могут повлиять на тесты. Параллельное использование одного эмулятора не проверялось.
- Три локальных прогона проверяют повторяемость только в данном окружении и не доказывают устойчивость на других устройствах, локалях или версиях приложения.
