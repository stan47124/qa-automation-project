## Проверка сайта перед реализацией

Проверены [главная](https://automationexercise.com/), [Products](https://automationexercise.com/products), [карточка Blue Top](https://automationexercise.com/product_details/1) и [Contact Us](https://automationexercise.com/contact_us). Дополнительно в реальном Chrome прочитан DOM карточки, диалога добавления, гостевой корзины и формы Contact Us.

Подтверждён товар Blue Top: ID 1, цена Rs. 500, категория Women > Tops, бренд Polo, состояние New, доступность In Stock. Проверяются и ID, и название; позиция товара в каталоге не используется.

Количество изменяется в input#quantity на странице товара. В корзине обнаружена только кнопка отображения количества .cart_quantity button, без редактируемого поля. Сценарий изменения количества реализован через выбор 4 на странице товара и проверку количества и суммы Rs. 2000 в корзине.

## Изменённые файлы

- `tests/ui/conftest.py`: function-scoped Chrome и Selene Browser, отдельный временный профиль в каждой сессии, finally/quit, тестовый товар и TXT через tmp_path.
- `tests/ui/storefront.py`: небольшой общий UI-помощник, переходы, поиск, карточка, добавление и проверка корзины; Allure-шаги.
- `tests/ui/test_storefront.py`: шесть новых сценариев.
- `tests/ui/test_product_search.py`: существующий PoC интегрирован с общими fixtures; имя теста и проверка результата сохранены.
- `tests/ui/test_contact_us_upload.py`: существующий PoC интегрирован с fixtures; добавлена проверка выбранного файла, отправки формы нет.
- `tests/ui/requirements.txt`: текущие версии pytest, Selene, Selenium и Allure.

API- и Mobile-код не изменялся и не запускался в этой задаче. Зависимости не переустанавливались.

## Изоляция и ограничения действий

Все тесты получают новый ChromeDriver и новый временный профиль без пользовательских cookies и сохранённой корзины. После каждого теста браузер закрывается. Гостевые корзины не связаны с аккаунтами. TXT создаётся в отдельном tmp_path; пользовательские файлы не используются.

В тестах применены подтверждённые ID, data-qa, data-product-id, href и классы с ограничением области поиска. Для выбора карточки используется :has с проверенным data-product-id, а не номер позиции. Ожидания выполняются Selene; time.sleep(), JS-клики и изменение корзины через API не используются. Единственный явный JS в тестах читает метаданные файла после его выбора через файловое поле.

Формы обратной связи и отзывов не отправлялись; аккаунты не создавались; заказы не оформлялись. Полный HTML в отчёты Selene не сохраняется, поскольку он может содержать CSRF-токены.

## Оставшиеся риски

- Проверено два последовательных прогона на локальном headless Chrome. Другие браузеры, размеры окна и параллельные запуски не проверялись.
- Изменение данных Blue Top приведёт к явному падению проверок; ожидаемые данные необходимо сверять с каталогом.
- Публичный сайт и сторонняя реклама могут влиять на доступность и клики. Во время обоих тестовых прогонов такой проблемы не наблюдалось; обход блоков и удаление элементов рекламы не применялись.
- Выбор количества покрыт на странице товара. Отдельного сценария прямого редактирования количества в корзине не заявлено, поскольку соответствующее поле не обнаружено.
